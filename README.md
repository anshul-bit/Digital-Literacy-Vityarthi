# Digital-Literacy-Vityarthi
# 📘 Digital Literacy Project

This repository contains my coursework for the **Digital Literacy (CSE0001)** subject at VIT Bhopal University. The project focuses on building awareness about responsible digital behavior, online safety, and essential tools required for students in the modern digital world.

---

## 🎯 Project Objectives

- Create a Digital Literacy Awareness Infographic  
- Build a Student Digital Portfolio  
- Explore Coding & Collaboration Platforms  
- Understand Email Etiquette & Professional Communication  
- Study Cybercrime Awareness & Prevention
