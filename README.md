# 📘 Digital Literacy Project

## 📌 Overview
This project focuses on promoting digital literacy, responsible online behavior, and professional digital presence among students. As a Student Digital Ambassador, the goal was to create awareness resources, explore essential digital tools, and develop skills useful for academic and career growth.
